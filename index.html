2. Konfigurasi Output FOH

Tentukan jumlah Group dan Aux (Mix Bus). M32 memiliki 16 Mix Bus bersama; Group otomatis diarahkan ke Main LR. Konfigurasi ini berlaku untuk mode FOH dan FOH + Monitor.

Aux 1–6 & FX Return 1–4 (Stereo)

Send Aux dan FX Return mengikuti Bus tujuan di atas. Nama FX return L/R terpisah; warna, EQ, Main LR, dan send berlaku pada pasangan stereo. Mematikan send tetap menyimpan level dB. Isi -oo untuk level −∞.

4. Konfigurasi Bus

Buat monitor stereo dengan satu tombol. Pasangan stereo menggunakan bus ganjil–genap.

🎧 Buka Semua Channel ke Mix Bus

Pilih Bus tujuan, kemudian buka semua input aktif ke −10 dB, −6 dB, atau 0 dB. Semua send otomatis ON. Berlaku juga untuk pasangan stereo Bus.

5. Assign Channel → Group / Main LR

Setiap channel dapat masuk ke beberapa Group sekaligus dan/atau langsung ke Main LR. Group Bus secara default menuju Main LR. Send CH → Group menggunakan 0 dB, POST.

6. DCA & Mute Group

Halaman khusus untuk memilih anggota DCA 1–8 dan Mute Group 1–6. Centang channel yang menjadi anggota; nama DCA dapat diubah. Tidak ada grup yang diaktifkan (mute) secara otomatis.

Atur FX 1–4 dan sumber input dari Mix Bus 1–16. FX 5–8 menyediakan 32 pilihan efek. FX 5–8 memiliki pilihan insert ke Mix Bus atau Main LR. Pengaturan FX return, send, dan parameter detail belum tersedia. Uji SCN secara offline.
