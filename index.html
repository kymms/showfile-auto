5. FX Rack — M32

Atur FX 1–4 dan sumber input dari Mix Bus 1–16. FX 5–8 menyediakan 32 pilihan efek. FX 5–8 memiliki pilihan insert ke Mix Bus atau Main LR. Pengaturan FX return, send, dan parameter detail belum tersedia. Uji SCN secara offline.

FX 5–8 memakai parameter dari scene referensi. Pilih tujuan Insert L dan Insert R: OFF, Ch 01–32, Bus 1–16, atau Main LR stereo. Main LR memakai kedua sisi FX (L → Main L, R → Main R). Pilih PRE/POST. Mengganti jenis FX mengembalikan kedua insert ke OFF. Satu tujuan hanya menerima satu sisi FX.
